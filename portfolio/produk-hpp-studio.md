# KATARINA HPP Studio v1 Offline

**Katalog produk digital • Harga rencana Rp49.000 • Belum tersedia untuk pembelian resmi.**

Kalkulator HPP untuk resep dan menu usaha kuliner yang bekerja di browser secara offline. Dirancang untuk membantu pemilik usaha menyusun komponen biaya secara konsisten dan membandingkan skenario harga jual.

## Yang termasuk

- Perhitungan biaya bahan per resep dan biaya per porsi.
- Konversi satuan bahan, biaya waste, kemasan, dan overhead.
- Simulasi margin serta harga jual berdasarkan input usaha.
- Ekspor data CSV/JSON untuk arsip dan pemeriksaan mandiri.
- Aplikasi dalam ZIP yang dibuka dari file `index.html` setelah diekstrak.

## Keterbatasan penting

Data disimpan dalam browser/perangkat setempat dan bisa hilang jika cache/storage dihapus. Pengguna perlu membuat cadangan secara berkala. Tidak ada sinkronisasi cloud, koneksi bank, pembayaran otomatis, pengelolaan stok, atau perhitungan pajak resmi. Hasil margin dan harga hanyalah simulasi dari data input, bukan jaminan laba.
