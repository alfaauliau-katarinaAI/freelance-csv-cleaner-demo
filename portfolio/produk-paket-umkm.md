# KATARINA UMKM Toolkit — HPP + Nota & Order

**Katalog bundel digital • Harga rencana Rp99.000 • Belum tersedia untuk pembelian resmi.**

Paket dua aplikasi offline untuk membantu menghitung HPP resep/menu dan mencatat order secara terpisah.

## Isi paket

1. **HPP Studio v1** — bahan, satuan, waste, kemasan, overhead, harga jual, CSV/JSON.
2. **Nota & Order Studio v1** — pesanan, pembayaran sebagian, nota cetak, CSV, backup/restore JSON.

Harga terpisah yang direncanakan Rp49.000 + Rp69.000 = Rp118.000; bundel Rp99.000 berarti selisih Rp19.000 dibanding membeli satuan pada harga rencana yang sama.

**Penting:** Kedua aplikasi **tidak terhubung dan tidak berbagi/sinkronisasi data**. Tidak ada stok real-time, bank/QRIS otomatis, penyimpanan cloud, atau fasilitas akuntansi pajak. Keduanya menggunakan data lokal browser; pelanggan wajib membuat backup masing-masing.
