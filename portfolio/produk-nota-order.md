# KATARINA Nota & Order Studio v1 Offline

**Katalog produk digital • Harga rencana Rp69.000 • Belum tersedia untuk pembelian resmi.**

Alat pencatatan pesanan dan pembuatan nota untuk usaha kecil yang dijalankan secara lokal di browser, tanpa layanan server.

## Yang termasuk

- Buat dan simpan catatan order; cari/filter pesanan.
- Pencatatan pembayaran sebagian serta sisa tagihan.
- Cetak nota, catat taksiran laba kotor, ekspor CSV.
- Cadangkan dan pulihkan data memakai berkas JSON.
- Aplikasi lengkap dalam ZIP yang dibuka lewat `index.html`.

## Keterbatasan penting

Penyimpanan berbasis perangkat/browser (localStorage), sehingga data bisa hilang jika storage browser dihapus atau perangkat rusak. Backup pengguna wajib dijaga sendiri. Opsi transfer atau QRIS **hanya catatan pembayaran manual**, bukan gateway, validasi transaksi, maupun integrasi rekening. Tidak ada sinkronisasi antarperangkat, manajemen stok otomatis, atau laporan pajak resmi.

**Status:** paket ZIP produk dan pengujian internal tersedia secara privat; **belum ada listing marketplace, pesanan, atau pembayaran terverifikasi**. Halaman GitHub ini bukan checkout dan tidak menyediakan ZIP lengkap kepada publik.
